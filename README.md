# CADPESSOAS.PY

Cadastro de Produtos

O programa de cadastro de produtos tem a função de armazenar e organizar informações sobre produtos em um sistema. Por meio dele, é possível registrar dados como nome do produto, preço, quantidade em estoque e categoria.

Além do cadastro, o sistema pode oferecer funcionalidades para listar, consultar, alterar e excluir produtos cadastrados. Essas informações são salvas em arquivos ou bancos de dados, permitindo um controle mais eficiente do estoque e facilitando a gestão dos produtos.

Esse tipo de programa é muito utilizado em comércios, empresas e lojas, pois ajuda a manter os dados organizados, reduz erros e agiliza o acesso às informações dos produtos.
